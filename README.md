# etc

My Arch Linux setup, public: dotfiles (GNU Stow), package lists, the public part of
`/etc`, wallpapers, and the runbook that brings this laptop back after a reinstall.
The desktop is [buchhwin-shell](https://github.com/buchhwin/buchhwin-shell) (a
generic shell; everything personal lives here, never there).

Nothing private is in this repository: no keys, passwords, tokens, host or share names,
network names, addresses, places or accounts. Those are listed **by name only** in the
private checklist below and come from the private backup. `bin/private-gate` checks
every commit (see "Updating").

## Layout

| Path | What | How it gets to the machine |
|---|---|---|
| `zsh/`, `starship/`, `alacritty/`, `fastfetch/` | shell, prompt, terminal, fastfetch (Saturn) | stow |
| `kde/` | Plasma: shortcuts, KWin, input, power, formats | stow (Plasma writes through the links: `git diff` shows changes) |
| `makepkg/` | `PKGDEST`: built AUR packages are kept in `~/.local/share/aur-packages` | stow |
| `wallpapers/` | `~/Pictures/Desktop/Wallhaven` - the **folder** is a link into this repo | stow (folded on purpose) |
| `pkglists/` | `native.txt`, `aur.txt`, `other-repos.txt`, `flatpak.txt`, `vscode-extensions.txt` | `install.sh`; regenerated by `bin/pkglists-save` |
| `system/` | public `/etc` files + `apply.sh` (units, groups, ufw, snapper) | `sudo system/apply.sh` (dry run first) |
| `bin/private-gate` | the private-data check (uses buchhwin-shell's rules) | `.githooks/pre-commit` |

## Restore (fresh install)

1. **Before** (old system, if it still runs): buchhwin-shell Settings › Profiles › Backups ›
   *Export* onto the private backup; `bin/pkglists-save` and commit; copy everything in the
   checklist below to the private backup.
2. **archinstall**: keep the Windows partitions; btrfs with `@`, `@home`, `@pkg`
   (`/var/cache/pacman/pkg`), `@log` (`/var/log`); snapper; systemd-boot with unified kernel
   images; zram; keyboard `de`, locale `en_US.UTF-8` + `de_DE.UTF-8`, your time zone; kernels
   `linux` + `linux-lts`. Consider LUKS2 + TPM2 this time. Secure Boot: restore the sbctl keys
   from the private backup, or setup mode + `sbctl create-keys && sbctl enroll-keys -m`.
3. **Clone** (as yourself, into `~/git`):
   ```bash
   mkdir -p ~/git && cd ~/git
   git clone https://github.com/buchhwin/etc.git
   git clone https://github.com/buchhwin/buchhwin-shell.git
   ```
4. **User setup** (dry run first): `~/git/etc/install.sh`, then `~/git/etc/install.sh --apply`.
   It installs the package lists (official, AUR via paru, Flatpak, VS Code extensions), stows
   the dotfiles and the wallpapers, runs buchhwin-shell's `install/bootstrap.sh --apply` and
   `scripts/deploy.sh --init`, and prints the checklist. Big AUR packages take hours to
   compile unless the kept packages are in `~/.local/share/aur-packages` (restore them from
   the private backup first).
5. **System** (root, dry run first), after the packages so that its units, groups and ufw
   rules find what they belong to: `sudo ~/git/etc/system/apply.sh`, read the diff, then
   `sudo ~/git/etc/system/apply.sh --apply`. It prints what to run after.
6. **Hyprland with the cursor patch**: buchhwin-shell's Arch build script (see its README).
7. **Shell setup**: Settings › Profiles › Backups › *Import* the private export.
8. **Private checklist** (`./install.sh --checklist`), then log out and in.

## Wallpapers

`~/Pictures/Desktop/Wallhaven` is a link to `wallpapers/Pictures/Desktop/Wallhaven`: a
picture saved there is in this repo's working tree at once. Publishing stays a step of its
own - never automatic:

```bash
cd ~/git/etc
git status --short wallpapers/          # what is new
bin/private-gate wallpapers/Pictures/Desktop/Wallhaven/NEW.jpg
exiv2 rm wallpapers/Pictures/Desktop/Wallhaven/NEW.jpg   # if it reports GPS/XMP/author (lossless)
git add wallpapers/Pictures/Desktop/Wallhaven/NEW.jpg && git commit -m "Wallpaper: ..."
```

`wallpapers/.gitignore` lets only `*.jpg *.jpeg *.png *.webp` in. Keep files under 50 MB.

## Updating

```bash
cd ~/git/etc
bin/pkglists-save                      # package lists, then look at git diff
git status --short                     # Plasma writes through the kde links
git add <the paths you mean>           # never "git add ." - wallpapers and new files are deliberate
git commit                             # .githooks/pre-commit runs bin/private-gate --staged
git push
```

## Manual Stow

```bash
cd ~/git/etc
stow --no-folding -t ~ zsh starship alacritty fastfetch kde makepkg
mkdir -p ~/Pictures/Desktop && stow -t ~ wallpapers   # the parent first, or stow links ~/Pictures itself
stow -D -t ~ <package>                 # remove the links again
```
